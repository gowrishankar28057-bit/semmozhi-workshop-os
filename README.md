# Semmozhi Workshop OS

A full-stack workshop and lifelong-learning management platform built for the AUREX'26 hackathon by **APEX Syndicate**.

**Track:** Track 01 — LMS / LLL Website Workshop & Learning Management Portal

## Overview

Semmozhi Workshop OS is a comprehensive learning management platform that enables:

- **Admins** to manage organizers and monitor platform statistics
- **Organizers** to create and manage workshops, sessions, and track attendance
- **Participants** to discover workshops, register, attend sessions, and earn certificates

## Core Features

### Authentication & Authorization
- Role-based access control (Admin, Organizer, Participant)
- Secure authentication system

### Admin Dashboard
- Organizer account management
- Platform statistics and overview

### Organizer Dashboard
- Workshop creation and management
- Session scheduling with meeting links
- Attendance tracking
- Resource management
- Announcement system
- Workshop analytics

### Participant Dashboard
- Workshop discovery and search
- Workshop registration
- Attendance tracking
- Certificate viewing and verification
- Resource access

## Certificates & Verification

Participants who attend **≥ 90%** of sessions receive certificates with:
- Unique certificate codes (e.g., `CICT-AUREX-2026-AB12CD`)
- Verification hash
- Public verification page at `/verify/[certificateCode]`
