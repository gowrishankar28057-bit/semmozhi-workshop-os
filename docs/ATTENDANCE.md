# Attendance

Eligible sessions are sessions included by workshop policy. `PRESENT` and currently `LATE` count as attended; `ABSENT` and `EXCUSED` do not unless policy changes explicitly. Percentage is `(attended / eligible) × 100`, rounded to two decimals; zero eligible sessions is 0% and never certificate-eligible. UI imports the shared 90% threshold and must not duplicate it. Attendance changes require organizer ownership and an audit event.
