# Design system

The visual language combines deep maroon (`#6e1731`), warm parchment (`#f7f0df`), restrained gold (`#c69b3c`), and dark charcoal (`#24211f`). Heritage appears through texture, Tamil details, and editorial rhythm—not ornamental imitation. Use high-contrast text, visible focus, generous spacing, rounded modern surfaces, and motion only when it clarifies state. English is default; Tamil strings use semantic `lang="ta"`. Components must remain keyboard and screen-reader usable.
