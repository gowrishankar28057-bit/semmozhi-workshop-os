# Product requirements

Semmozhi Workshop OS serves ADMIN, ORGANIZER, and PARTICIPANT roles. The core success path is organizer provisioning → workshop/session publishing → participant registration → verified attendance → certificate at 90% → public verification. Differentiators are rotating QR attendance, Learning Passport, durable archives, workshop communities, bilingual English/Tamil foundations, learning pathways, notifications, and role-specific analytics. Foundation code must never imply an unimplemented workflow is complete.
