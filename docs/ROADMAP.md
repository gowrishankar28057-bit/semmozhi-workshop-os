# Roadmap

1. **P1 vertical slice:** Auth.js sessions, server RBAC, audited admin-created organizer.
2. **Workshop operations:** organizer-owned workshop/session CRUD and publishing.
3. **Participant path:** discovery, registration, registered-workshop workspace.
4. **Trust layer:** persistent attendance, rotating QR replay prevention, certificate PDF/verification.
5. **Continuity:** Learning Passport, archives, communities, notifications, analytics.
6. **Production:** security review, accessibility/performance testing, Neon migrations, Cloudflare deployment and observability.
