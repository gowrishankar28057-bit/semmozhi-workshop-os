# User flows

1. Admin signs in, creates an organizer, and the system audits it.
2. Organizer creates a draft workshop, adds sessions/resources, and publishes it.
3. Participant discovers and registers before the deadline/capacity limit.
4. Organizer opens session attendance; participant checks in with a rotating QR.
5. System calculates attendance from authoritative records.
6. At 90% or higher, organizer/system issues a verifiable certificate.
7. Completion writes a Learning Passport record and keeps the workshop as an archive/community.
